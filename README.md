# Пристань 35 · Pristan 35

Эко-курорт с форелевым хозяйством на Иссык-Куле (с. Григорьевка-Пристань): мастер-план и инвестиционная модель с 3D.

Сайт: https://etbhitro.github.io/pristan35/ · китайская версия сразу: https://etbhitro.github.io/pristan35/?lang=zh

- Языки: русский и китайский (переключатель RU / 中文 на экране входа и в шапке). Китайский — слой перевода поверх страницы (словарь и правила для чисел и сумм, $ млн → 万美元).
- Список объектов у мастер-плана можно свернуть, чтобы план занял всю ширину.
- Вход по паролю — заставка, а не защита: в коде хранится только SHA-256 пароля, но сама страница открыта.
